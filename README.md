# cloud-itonami-iso3166-bhr

Open ISO 3166 Blueprint for **BHR**: Kingdom of Bahrain.

Independent public-sector market-entry & procurement-compliance service
for an already-incorporated operator entering public contracts in Bahrain.

## Official surface (web-verified)

- Procurement: Tender Board e-procurement / bahrain.bh tender portals
- Business/tax: Sijilat commercial registration + CR number via Ministry of Industry and Commerce

## What this is NOT

- **Not the government of Bahrain.**
